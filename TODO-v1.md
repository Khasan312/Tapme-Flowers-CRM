# Tapme Flowers · что осталось до первой версии

Обновлено: 12 сентября 2026. Макет: tapme-flowers-v1.html (артефакт версии 10).
Отмечать сделанное: `[x]`.

## Уже есть в макете

- Домашний экран «Заказы»: плитки с таймерами, доска, список, календарь; срезы по дням; поиск; панель задач.
- Панель заказа: клиент, получатель с ID и заметкой, доставка с курьером, хронология, фото, состав и оплата, отзыв и жалоба, история.
- Форма заказа: подстановка клиента по телефону, получатели с телефоном и адресом, прайс, оплата, комментарии.
- Клиенты: список с ID, карточка (получатели, даты, заметки, заказы, отзывы, сообщения), импорт в три шага, новый клиент, новый получатель, новая дата.
- Напоминания: простой список (даты 14/7/3/накануне и 90+ дней), шаблоны с WhatsApp click-to-chat, отметка «написал», пауза при открытой жалобе.
- Доставка: по окнам, курьеры, Яндекс, назначение курьера.
- Настройки: сотрудники, окна, шаблоны, прайс, магазин.
- Телефон: страница флориста, страница курьера, страница статуса заказа для клиента с «Как вам букет?».
- Жалобы как задачи с исходом, опрос через два часа после вручения.
- ID: клиенты 1xxxxx, получатели 2xxxxx, заказы № и код TF-XXXXXX, поиск по всем.
- Подсказки на навигации и кнопках, горячие клавиши N и /.

## Решить (блокирует работу над макетом)

- [ ] **Напоминания: где живут шаблоны и правила.** Структура «Очередь» (вариант A) выбрана. Осталось выбрать между A1 (вкладки Очередь · Шаблоны · Правила · Статистика) и A5 (подменю в навигации). Рекомендация: A1, карандаш из A2 вторым шагом. Холст: https://claude.ai/code/artifact/f7752eae-1687-46e0-9437-b7349f5f0d2d
- [ ] **Статус «Новый».** Переименовать в «Ждёт флориста» и показывать время ожидания на доске и в списках (на плитках уже так).
- [ ] **Название магазина в демо.** Gul Studio оставить или заменить на нейтральное для показов другим магазинам.
- [ ] **Роли на десктопе.** Что видит владелец и флорист в кабинете, или кабинет только для менеджера, а остальные на телефоне.

## Доделать в макете

### Напоминания
- [ ] Собрать режим «Очередь»: список слева с прогрессом, справа карточка клиента с поводом, прошлым заказом, заметкой, шаблон, предпросмотр, кнопка «Открыть WhatsApp и перейти к следующему».
- [ ] «Пропустить в этом году» и «Напомнить завтра» с записью в карточку.
- [ ] Режим «Список» как второй вид на той же странице.
- [ ] Вкладка «Шаблоны»: список с цифрами по каждому, редактор с подстановками, предпросмотр, «где используется».
- [ ] Вкладка «Правила»: тумблеры за 14/7/3/накануне, 90 дней, тихие часы, только с согласием.
- [ ] Вкладка «Статистика»: написали, ответили, заказали, лучший шаблон.
- [ ] Убрать дубль: шаблоны в «Настройках» превратить в ссылку на вкладку напоминаний.
- [ ] История напоминаний в карточке клиента (написали, ответ, заказ).

### Заказы и панель заказа
- [ ] Переименование статуса «Новый» (после решения выше).
- [ ] Отмена заказа: причина и сообщение клиенту.
- [ ] Редактирование заказа из панели (сейчас только статусы, курьер, оплата).
- [ ] Печать или показ талона флористу с десктопа, если флорист без телефона.
- [ ] Проверить перенос плиток на 13-дюймовом ноутбуке: две колонки, кнопки не ломаются.

### Клиенты
- [ ] Сохранение заметки клиента и заметок получателей (сейчас поля без кнопки «Сохранить»).
- [ ] Объединение дублей клиентов по телефону вручную.
- [ ] Экспорт клиентов в Excel из настроек (кнопка есть, экрана нет).

### Доставка
- [ ] Согласовать с плитками: та же группировка по окнам и те же таймеры.
- [ ] Страница курьера: «не дозвонился» должна создавать задачу менеджеру (в макете флаг ставится, задача есть).

### Телефон
- [ ] Страница флориста: показ заметок получателя проверить на реальных флористах, размер кнопок под палец.
- [ ] Страница статуса: кнопка «Позвонить» и «Написать магазину» с реальными номерами магазина из настроек.

### Общее
- [ ] Экран входа и выбора роли (сейчас «Выйти» просто перезагружает).
- [ ] Первый запуск нового магазина: название, сотрудники, окна доставки, шаблоны по умолчанию, импорт.
- [ ] Пустые состояния: нет заказов на день, нет задач, нет напоминаний, пустой импорт.
- [ ] Мобильная вёрстка кабинета менеджера (сейчас рассчитан на ноутбук, телефон только у флориста и курьера).
- [ ] Согласованность демо-данных: суммы в карточках, «24 заказа» против списка, даты в ленте.
- [ ] Визуальная проверка в браузере всех экранов и подсказок (в этой среде макет не отрисовывался, проверено только логически).

## Для пилота, вне макета

- [ ] Спецификация первой версии по макету: экраны, данные, роли, границы (без Poster, ККМ и склада).
- [ ] Одностраничное предложение магазину: бесплатно до 15 марта в обмен на заказы через Tapme, импорт базы, полчаса обратной связи в неделю, отзыв.
- [ ] Три метрики пилота: доля удалённых заказов в Tapme, напоминания превратившиеся в заказ за 14 дней, доставки вовремя и с фото.
- [ ] Пять вопросов магазину до кода: доля удалённых заказов, где живёт база, личный WhatsApp или бизнес, доля Яндекса, как заказ передаётся флористу.
- [ ] Импорт реальной базы: формат выгрузки Poster и Excel, правила дедупликации.
- [ ] Шаблоны сообщений на кыргызском и русском, согласие на сообщения.
- [ ] План разработки: 6–8 недель при двух разработчиках, запуск не позже середины ноября, пилот до 15 марта.

## Отложено на вторую версию

- Poster и ККМ как адаптер кассы, попадание прилавка в историю клиента.
- Склад, партии, себестоимость, списания.
- Бонусы и лояльность.
- WhatsApp Business API: автоотправка, массовые рассылки, ответы клиентов в приложении.
- RFM, вероятность оттока, ИИ-тексты, разбор сообщений клиента в заказ.
- API Яндекс Доставки, карта курьеров.
- Несколько точек, корпоративные счета.
- Казахстан и Узбекистан: валюта, ККМ, платежи, Telegram.
