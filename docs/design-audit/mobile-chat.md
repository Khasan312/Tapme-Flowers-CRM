# Полноэкранный мобильный диалог и клавиатура

Основа — снимок пользователя с iPhone и существующий интерфейс TapMe. Замер
исходного Instagram-примера на ширине 390 px показал **13 px** у textarea;
общий composer использует 14 px. Такое поле провоцирует увеличение страницы
Safari при фокусе. Высота чата до исправления основана на `100dvh`, без слежения
за уменьшением visual viewport при появлении экранной клавиатуры.

| Решение | Источник | Ограничение |
|---|---|---|
| Диалог занимает доступный экран | Прямой запрос пользователя | Нижняя навигация и переключатель каналов остаются в списке чатов |
| В открытом диалоге есть заметный возврат к списку | Существующие кнопки WhatsApp / Instagram | Навигация сохраняется без постоянной панели под сообщением |
| Размер поля ввода от 16 px | Фактический размер 13 px, iPhone-снимок, Refero craft-details | Сохраняется пользовательское масштабирование страницы |
| Высота и смещение берутся из VisualViewport | Наблюдаемое появление клавиатуры | Обновление через requestAnimationFrame, без перерисовки React на каждый кадр |
| Во время работы клавиатуры скрываются второстепенные строки | Запрос удобства переписки | Название, возврат, профиль и поле отправки остаются; действия возвращаются при закрытии клавиатуры |
| Мобильный Enter — новая строка; отправка кнопкой | Поведение мобильного чата | На компьютере сохраняется Enter для отправки и Shift+Enter для новой строки |
| Последнее сообщение закрепляется при resize | Найденный дефект: сообщение оказалось за нижней границей thread | При чтении старой истории позиция сохраняется; проверено через ResizeObserver |
| Одинаковое поведение обоих каналов | Общий Chats и Instagram-пример | Отдельная проверка API-диалогов с fake-провайдером; не выдавать её за доставку Meta |

Основной визуальный источник — действующая CRM. Live Refero ранее вернул
`NO_SUBSCRIPTION`; использованы доступные bundled craft-details и текущие экраны.

Проверено: исходные 13 px заменены на 16 px; 320/390 px без бокового переполнения,
composer в видимой области при высоте 320/430 px, emoji, сохранение недописанного
текста, обратная навигация, сохранение фокуса при отправке, desktop Enter. Четыре
сообщения прошли UI → API → очередь → fake-provider acknowledgement в обоих
каналах. Временная E2E-компания удалена. Нативная iOS-клавиатура и реальная доставка
Meta не проверялись; они не подменяются результатами эмуляции и fake-провайдера.
