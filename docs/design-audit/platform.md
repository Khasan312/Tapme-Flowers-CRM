# Панель TapMe: визуальные решения

Цель: подключить компанию и передать первый доступ владельцу, который затем сам
добавляет сотрудников. Основной образец — существующая CRM и её дизайн-система,
без смены визуального направления.

Live Refero вернул `NO_SUBSCRIPTION`. Для исследования использованы существующие
экраны настроек/сотрудников и bundled Refero craft-details / anti-ai-slop: явные
подписи полей, доступные формы, состояния ошибок, умеренная плотность, отсутствие
декоративных карточек и фиктивных показателей.

| Решение | Источник | Применение |
|---|---|---|
| Тёмно-зелёное меню, светлая рабочая область | `frontend/src/reference.css`, действующая CRM | Сохранены роли `rail`, `surface`, `ink`, шрифты Golos Text / IBM Plex Mono |
| Фиолетовый акцент | Действующая CRM | Основное действие «Подключить магазин», без декоративных заливок |
| Один реестр с числом компаний, точек и пользователей | Запрос пользователя, существующая таблица сотрудников | Реальные агрегаты, без графиков и отдельных карточек показателей |
| Формы создания и восстановления в диалоге | Существующий `Modal`, Refero craft-details | Подписи полей, ошибки рядом с формой, блокировка повторной отправки |
| Отдельный результат с первым доступом | Сценарий пользователя | Скопировать адрес/логин/временный пароль; при потере выдать новый |
| Первый вход владельца | Сценарий выдачи доступа, существующая смена пароля | Отдельный обязательный шаг, серверная проверка до доступа к CRM |
| Узкий экран | Существующая адаптивная CRM, Refero craft-details | Вертикальное меню и строки с подписями вместо широкой таблицы |

Границы: компания — `Business`, филиал — `Shop`, владелец — роль `owner` в
`Membership`. Панель TapMe имеет отдельное серверное право. Пользователь магазина
не получает платформенные права из имени, префикса логина или `is_staff`.
