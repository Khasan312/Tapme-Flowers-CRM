# Подключение Instagram Direct

Первый рабочий вариант использует ручное подключение через **Instagram API с
единым входом (Unified Login)**. Это отдельный канал рядом с WhatsApp. Вход
через OAuth из CRM пока не реализован; для пилота токен берётся из панели Meta.

## Подготовка

1. Профессиональный аккаунт Instagram, Meta-приложение со сценарием Instagram.
2. Конфигурация Unified Login с `instagram_basic` и `instagram_manage_messages`.
   Для тестирования аккаунт должен иметь необходимый доступ в приложении Meta;
   подключение сторонних магазинов требует соответствующего доступа Meta.
3. На сервере: корректный `TAPME_SECRETS_KEY`, `META_GRAPH_VERSION` и
   `TAPME_META_MODE=live`. В `fake` запросы в Meta не выполняются.
4. Обновлённые API/worker/beat и миграция
   `messaging.0004_remove_conversation_chat_channel_phone_and_more`.

## Подключение владельцем

1. Открыть **Настройки → Каналы → Instagram · сообщения Direct**.
2. Вставить Instagram Account ID, Access token Unified Login и App Secret
   **Meta-приложения**. Не вставлять номер телефона, WhatsApp-токен или пароль
   от Instagram. Нажать «Проверить и подключить Instagram».
3. Сервер проверяет ID/username через `graph.facebook.com`, шифрует секреты.
   Токен и App Secret API обратно не возвращает. После сохранения поля очищаются.
4. В Meta → Unified Login → Webhooks указать Callback URL и Verify token из CRM.
   Если CRM открыта на localhost, заменить origin на публичный HTTPS-адрес того же
   сервера, сохранив путь `/api/v1/webhooks/meta/instagram/<ключ>/` целиком.
   Публичный шлюз должен пропускать GET/POST этого пути. Не открывать ради этого
   остальные API, вход в CRM или медиа.
5. Выбрать в Meta поля `messages` и `messaging_seen`. После успешной проверки
   Callback URL нажать в CRM «Проверить доступ Instagram», затем
   «Включить подписку Instagram». Подписка вызывает `/<IG_ID>/subscribed_apps`.
6. Написать магазину с другого разрешённого аккаунта. В **Чаты → Instagram**
   появится сообщение. Ответить и проверить получение на телефоне. Чек-лист
   отдельно показывает первое входящее и первый отправленный из CRM ответ.

Не считать зелёную проверку токена или синтетический вебхук подтверждением
реальной доставки. Текущий публичный туннель WhatsApp автоматически Instagram
не пропускает; отдельный маршрут требует настройки.

## Поведение и ограничения первого варианта

- Входящие проверяются HMAC-SHA256 до сохранения, дубли дедуплицируются.
  Обработка inbox/outbox выполняется существующим worker; HTTP webhook не
  ждёт отправки ответов. ID аккаунтов Instagram хранятся отдельно от телефонов.
- Текст, emoji и ответ с цитатой поддерживаются. Лимит исходящего текста —
  1000 байт UTF-8. Ответы ограничены стандартным окном 24 часа; исключения для
  рекламы/оператора пока не используются. Неоднозначная отправка получает
  `unknown` без автоматического повтора. Эхо с известным mid не дублирует ответ.
- Вложения представлены пояснением открыть Instagram. Загрузка файлов и QR
  из CRM пока отключены. Автоответ WhatsApp к Instagram не применяется.
- Для карточки/заказов/черновика менеджер связывает переписку с существующим
  клиентом своего магазина или создаёт карточку с реальным номером клиента.
  Собеседники Instagram не объединяются с WhatsApp по похожему ID или имени.
- Папки общие у магазина; счётчики и списки фильтруются по выбранному каналу.
  Уведомления открывают правильный канал. Выбранные диалоги и черновики ответов
  сохраняются раздельно при переключении.
- Отключение очищает секреты и останавливает приём/новые отправки, сохраняя
  историю и заказы. Повторно подключается тот же Instagram, чтобы не смешать
  историю аккаунтов. Уже переданный Meta запрос может завершиться после отключения.
- Без подключения остаётся явно отмеченный интерактивный пример. После первого
  подключения показывается серверная история, в том числе после отключения.
