# 10. План работ, задачи и пилот

Оценка размера: **S** — до 2 дней, **M** — 3–5 дней, **L** — 6–10 дней одного
разработчика с ИИ-агентом. Общая оценка для двух разработчиков — **9–12 недель**;
уточняется после исследований S-01…S-05 (неделя 1).

Критический путь: **S-01 (Meta) → T-11 (подключение WhatsApp) → T-29/T-30 (бот) →
пилот.** Разработка каналов идёт на тестовом номере Meta, не дожидаясь одобрений;
одобрения нужны только для запуска пилота.

## Пилот

**Готовность к запуску (все пункты):**
- [ ] Все P0-требования фаз 1–5 выполнены и отмечены в отчётах задач.
- [ ] Сквозные сценарии NFR-TS-005 проходят в Chromium и Firefox.
- [ ] Точность ИИ на наборе S-04 ≥ 85 % (или ИИ выключен, черновик ручной — осознанное решение).
- [ ] У партнёра: приложение Meta одобрено (или подключение через BSP), номер для
      заказов активен, имя одобрено, шаблоны одобрены, Instagram подключён (или пропущен).
- [ ] Политика конфиденциальности опубликована; согласие партнёра на обработку данных
      клиентов оформлено.
- [ ] Резервное копирование и восстановление проверены на рабочем сервере.
- [ ] Инструкции T-35 готовы; встреча подключения проведена.

**Ход пилота (4 недели):**
- Неделя 1 — ежедневный разбор с менеджером партнёра (15 минут): что мешает, где бот
  ошибся, где ИИ ошибся в черновике.
- Неделя 2 — первый срез метрик G1–G5 (раздел 2 [00](00-product-overview.md)).
- Недели 3–4 — правки по результатам, решение о подключении следующих магазинов.

**Метрики собираются автоматически:** источник заказа, время первого ответа, доля
автосозданных клиентов, качество номера, конверсия напоминаний (FR-CR-070 —
временно запросом к базе, если T-41 не сделан).

**Правило сокращения рамок:** если фаза отстаёт больше чем на неделю, сначала
переносятся P1, затем P0 фазы 4 «Собрать на бюджет» (бот делает handoff сразу), затем
Instagram (пилот только на WhatsApp). Подключение WhatsApp, чаты, черновик, `pending`,
QR и проверка оплат не сокращаются.
