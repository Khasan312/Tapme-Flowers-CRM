# 11. Открытые вопросы и риски

## Открытые вопросы

«Блокирует» — нельзя начинать связанную задачу без ответа. Ответ записывается сюда
с датой и переносится в журнал решений ([00](00-product-overview.md#6-журнал-решений)).

## Риски

| № | Риск | Вероятность / влияние | Меры | Ответственный |
| --- | --- | --- | --- | --- |
| R-01 | Проверка бизнеса и приложения у Meta затягивается — пилот без канала | средняя / высокое | Начать в неделю 0 (S-01); разработка на тестовом номере; запасной путь через BSP; заранее подготовить политику и видео демонстрации | сооснователи |
| R-02 | Клиенты продолжают писать на основной номер — заказы не попадают в CRM (G1) | высокая / высокое | Автоответ на основном номере; ссылка в Instagram, на сайте, в напоминаниях; QR в магазине и на открытках; менеджер переводит вручную; метрика с первой недели | партнёр + продукт |
| R-03 | Понижение качества или ограничение номера для заказов | низкая / высокое | Никаких маркетинговых сообщений первыми через API; «стоп» уважается; только utility-шаблоны; мониторинг качества и предупреждения | продукт |
| R-04 | ИИ ошибается в датах, адресах, позициях | средняя / среднее | Только черновик; подсветка «уточнить»; правка человеком; набор S-04 перед каждым изменением | разработка |
| R-05 | Поддельные скриншоты оплаты | средняя / среднее | Обязательная сверка менеджером; подсказка в интерфейсе; журнал подтверждений; позже — QR с автоподтверждением через провайдера | партнёр |
| R-06 | Push на iPhone не работает без установки приложения | высокая / среднее | Экран первого входа; «Готовность команды»; Telegram-дубль (P1); звук в открытой CRM | разработка |
| R-07 | Объём релиза велик для двух разработчиков | высокая / высокое | Фазы с критериями выхода; P1 вне критического пути; правило сокращения рамок в [10](10-roadmap.md) | сооснователи |
| R-08 | Поток событий (SSE) нестабилен за прокси/мобильными сетями | средняя / низкое | Запасной путь — опрос; пинги; переподключение с досылкой | разработка |
| R-09 | Переход на несколько точек ломает существующую логику заказов и доставок | средняя / высокое | Миграция на копии базы; обратная совместимость эндпоинтов; полный прогон существующих тестов; поведение для одной точки не меняется | разработка |
| R-10 | Meta меняет правила для ботов или цены | низкая / среднее | Бот детерминированный, ИИ только внутри CRM; цены и категории из вебхуков; учёт расходов | продукт |
| R-11 | Клиент получает сообщения с двух номеров (напоминание с основного, заказ с номера для заказов) и путается | средняя / низкое | В тексте напоминания — «Оформить заказ: wa.me/…»; одинаковое имя магазина в обоих | партнёр |
| R-12 | Стоимость ИИ растёт с объёмом переписки | низкая / низкое | Кэширование системной инструкции; задержка и объединение вызовов; лимит сообщений в запросе; решение Q-12 по модели | разработка |
| R-13 | Утечка токена канала | низкая / высокое | Шифрование, отсутствие в логах, отключение канала из админки, ротация ключа | разработка |
