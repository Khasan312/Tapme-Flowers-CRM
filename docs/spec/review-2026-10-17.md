## Границы результата

Спецификацию можно слить **как черновик следующего релиза**. Продуктовые вопросы
Q-01…Q-22 и исследования S-01…S-05 остаются обязательными перед связанными задачами.
Их ответы не считаются утверждёнными этим ревью. Особенно: доступ Meta, тарифы,
согласия/хранение данных, срочная доставка и неоднозначные номера.

Реальные WhatsApp/Instagram, платежи, новые миграции, конкурентность будущего
серверного кода и Web Push в этом PR проверить невозможно: реализации ещё нет.
При её появлении нужны проверки из соответствующих FR/NFR, включая регрессии
существующей CRM.

Для проверки утверждений о тарифах просмотрена
[официальная страница WhatsApp](https://business.whatsapp.com/products/platform-pricing):
категории и условия тарификации различаются, открытое окно не означает бесплатность
всех типов сообщений. Страницы Meta Developer о доступе Instagram вернули HTTP 429;
точные условия оставлены для проверки S-02 перед пилотом.
Модели из Q-12 сверены с
[официальным перечнем Claude](https://platform.claude.com/docs/en/models/overview);
выбор модели остаётся результатом измерений S-04.
